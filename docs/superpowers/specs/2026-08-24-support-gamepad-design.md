# FriendshipAssistant 手柄送礼推荐设计

> 日期：2026-08-24  
> 状态：实现与自动验证已完成，待游戏内手柄验收

## 1. 背景与目标

FriendshipAssistant 当前的送礼推荐弹窗主要依赖鼠标点击、鼠标滚轮和滚动条拖动。目标是在不改变现有鼠标和键盘行为的前提下，为推荐弹窗增加完整的 Stardew Valley 原生手柄体验。

目标包括：

- 使用左摇杆、方向键和右摇杆在礼物网格内导航。
- 使用确认键选择礼物，使用 X 直接执行“今日不再提示”。
- 使用取消键关闭整个推荐弹窗。
- 支持背包页与存储页切换。
- 支持长礼物列表的焦点自动滚动和快速滚动。
- 保证 Xbox、PlayStation 和 Switch 等控制器使用同一套逻辑输入语义。

## 2. 范围

### 2.1 本次包含

- `GiftSuggestionMenu` 的原生 Snappy/ClickableComponent 焦点导航。
- 仅礼物格进入手柄焦点链。
- 礼物网格的自动滚动、可视区域导航和扳机快速滚动。
- 空背包、空存储页、失效礼物项等边界状态。
- “今日不再提示”记录增加游戏年份，修复跨年误抑制。
- GMCM 文案明确 `AutoGift` 只从背包选择礼物。

### 2.2 本次不包含

- 游戏内自定义手柄按键映射的读取或覆盖。
- Xbox、PlayStation、Switch 等控制器品牌识别。
- 控制器专属按键图标或按键提示绘制。
- `AutoGift` 从存储设备自动取出并送礼。
- 送礼业务规则、NPC 喜好算法或存储设备范围的重新设计。

## 3. 交互方案

采用 Stardew Valley 原生 Snappy 菜单导航作为手柄路径，同时保留现有鼠标路径。手柄输入和鼠标输入最终调用同一套送礼、关闭和提示抑制回调，不复制业务逻辑。

### 3.1 输入语义

使用 MonoGame/Stardew 的逻辑按钮，不绑定实体控制器品牌：

| 逻辑输入 | 行为 |
| --- | --- |
| 左摇杆 | 使用原生 Snappy 导航选择礼物 |
| 方向键 | 使用原生 Snappy 导航选择礼物 |
| 右摇杆 | 左右选择礼物并将鼠标指针同步到新礼物中心；上下滚动礼物网格且不移动指针 |
| A / 确认键 | 选择当前礼物 |
| B / 取消键 | 始终关闭整个推荐弹窗 |
| X | 记录“今日不再提示”并关闭推荐弹窗 |
| LB | 切换到背包页 |
| RB | 切换到存储页 |
| LT（ZL） | 向上滚动一个可视区域 |
| RT（ZR） | 向下滚动一个可视区域 |

当存储页未启用时，LB/RB 不执行页面切换。顶部和底部控件都不进入手柄焦点链：B 直接关闭弹窗，X 直接执行“今日不再提示”。左摇杆和方向键通过原生 Snappy 邻接关系选择礼物；右摇杆左右选择礼物并同步指针，上下滚动礼物网格但不移动指针。LT/RT（ZL/ZR）继续提供整页快速滚动。

### 3.2 焦点区域

菜单手柄焦点只有一个区域：

```text
礼物区域：按喜好分组的可送礼物品
```

以下元素创建可导航组件：

- 当前页面中的可送礼物格。

关闭按钮、页面切换按钮和“今日不再提示”按钮不进入手柄焦点链；B、X、LB/RB、LT/RT（ZL/ZR）直接执行对应操作。分类标题、空白格和无效礼物不进入焦点链。底部按钮仍保留鼠标悬停与点击行为。

### 3.3 初始焦点和页面切换

- 背包存在礼物时，菜单打开在背包页，焦点放在排序后的第一个可送礼物。
- 背包没有礼物但存储页有礼物时，菜单直接打开存储页并聚焦第一个存储礼物。
- 背包和存储都没有可送礼物时，不打开菜单。
- 每次打开菜单时，当前页面滚动到顶部，选择第一个可送礼物，并将鼠标指针移动到该礼物中心。
- 每次切换背包页或存储页时，目标页面滚动到顶部，选择第一个可送礼物，并将鼠标指针移动到该礼物中心；不恢复该页上次焦点或滚动位置。
- 目标页面为空时不设置手柄焦点；LB/RB、B 和 X 仍可直接操作。

### 3.4 网格导航和滚动

- 礼物格按从左到右、从上到下导航。
- 左摇杆和方向键通过原生 Snappy 邻接关系在礼物网格中移动。
- 网格边缘缺少邻居时使用 Stardew 的忽略邻居语义，不把当前礼物设置成自己的邻居；在四角向外推动后，反向输入仍应立即生效。
- 右摇杆左右只在当前可视礼物行内移动，遇到行边界时保持焦点不变；成功移动后鼠标指针同步到新礼物中心。
- 礼物网格到达首行或末行后继续移动，焦点保持在当前礼物，不进入顶部或底部控件。
- 右摇杆上下滚动礼物网格，不移动鼠标指针。
- LT/RT（ZL/ZR）的短按分别向上/向下滚动一个可视区域，并把焦点移动到新视区的对应列。
- LT/RT（ZL/ZR）长按按游戏输入重复节奏连续滚动；滚动到边界后停止，不循环。
- 到达滚动边界后继续按对应方向不循环跳转。

### 3.5 鼠标与手柄焦点

- 鼠标移动到可点击元素时，焦点同步切换到该元素。
- 手柄移动焦点时，鼠标悬停状态不能阻止手柄焦点移动。
- 右摇杆横向移动后，鼠标指针与礼物焦点保持在同一个礼物格中心。
- 最后一次输入设备决定主动焦点，但鼠标和手柄都可以继续操作菜单。
- 手柄焦点礼物格使用与鼠标悬停相同的高亮效果。
- 手柄焦点存在时，显示该物品的名称和原版描述 tooltip。
- 手柄 tooltip 锚定在当前聚焦礼物格附近，不使用鼠标上次停留位置。
- 根据屏幕边界自动选择礼物格左侧或右侧显示 tooltip。
- tooltip 纵向位置与焦点格对齐，并在菜单和屏幕边界内夹取。
- 鼠标悬停时优先显示鼠标对应的 tooltip。
- 当前页面没有礼物焦点时隐藏礼物 tooltip。
- 不额外绘制品牌专属焦点框，沿用 Stardew 菜单组件的高亮风格，不增加永久文本面板。

LT/RT 快速滚动后的焦点规则：

- 优先保持滚动前的列位置。
- 目标行没有该列时，焦点夹取到目标行最右侧的最后一个可用礼物。
- 目标页面没有礼物时不设置手柄焦点。
- 焦点不能落在空白格或分类标题上。

### 3.6 操作结果

- A 选择礼物后，调用现有送礼逻辑；送礼成功则消耗一件物品、记录历史并关闭菜单。
- X 在任意手柄焦点状态下立即记录当天抑制状态并关闭菜单，不弹出二次确认。
- B 在背包页和存储页都直接关闭整个菜单，不记录抑制状态。
- 鼠标点击、滚轮、滚动条拖动、键盘和关闭按钮行为保持现状。

## 4. 失效状态与错误处理

手柄聚焦期间，物品可能被其他操作消耗、移动或从存储设备移除。A 确认时必须重新验证：

- 物品仍存在。
- 数量大于 0。
- 来源容器仍可访问。
- 物品仍可作为礼物。

验证失败时：

- 不关闭菜单。
- 不记录送礼历史。
- 重新扫描当前页面并移除失效项。
- 焦点移动到最近的可用礼物。
- 页面为空时清除手柄焦点；LB/RB、B 和 X 仍可用。

## 5. 存档数据修复

当前 `PromptSuppressionEntry` 只记录季节和日期，会导致下一年同日继续抑制提示。本次将其扩展为：

```json
{
  "Season": "spring",
  "Day": 13,
  "Year": 1
}
```

抑制条件改为 NPC、游戏年份、季节和日期全部匹配。

旧存档兼容规则：

- 缺少 `Year` 的旧记录反序列化为 `Year = 0`。
- `Year = 0` 的记录视为无效，不再抑制提示。
- 玩家下一次选择“今日不再提示”时写入完整年份。
- 不尝试推断旧记录所属年份。

## 6. GMCM 文案

`AutoGift` 的名称和说明必须明确：自动交好只会从玩家背包中选择礼物，不会从存储设备取出物品。

`ShowStorageItems` 的说明继续明确：该设置只影响手动送礼推荐页，并可能影响游戏平衡。

## 7. 兼容性

- 使用 Stardew Valley / MonoGame 的逻辑手柄按钮，不区分控制器品牌。
- 不读取或覆盖游戏内自定义手柄按键映射。
- 不显示控制器品牌专属按键图标。
- 在游戏或 Steam Input 能识别控制器的前提下，Xbox、PlayStation 和 Switch 控制器使用一致的逻辑行为。
- 鼠标和键盘交互必须保持向后兼容。

## 8. 验收标准

### 手柄核心流程

- 手柄可聚焦并选择所有非空礼物格。
- A 送礼成功后菜单关闭且只消耗一件物品。
- B 在背包页和存储页都关闭菜单。
- LB/RB 在启用存储页时切换背包和存储页。
- LT/RT 可快速滚动长列表。
- 左摇杆和方向键可在礼物网格内逐格移动焦点。
- 打开菜单或切换背包/存储页后，默认选择目标页第一个礼物，鼠标指针位于该礼物中心。
- 四个角落向外输入后，反向输入无需右摇杆介入即可立即恢复移动。
- 右摇杆左右移动礼物焦点时，鼠标指针同步到新礼物中心。
- 右摇杆上下滚动礼物网格时不移动鼠标指针。
- 礼物焦点不会进入顶部或底部操作控件。
- X 执行“今日不再提示”后当天不再弹出提示。

### 空状态与异常

- 空背包但有存储礼物时直接打开存储页。
- 空存储页不会造成焦点锁死。
- 背包和存储均为空时不打开菜单。
- 失效物品不会误送礼、误扣物品或误记历史。

### 数据与配置

- 下一年同季节同日期不会被上一年的抑制记录错误屏蔽。
- 旧存档缺少年份时不会继续抑制提示。
- GMCM 文案准确说明 AutoGift 只使用背包。

### 非回归

- 鼠标点击礼物、滚轮滚动、拖动滚动条、页面按钮、关闭按钮和“今日不再提示”行为保持不变。
- 现有礼物喜好分类、排序、物品消耗、历史记录和存储设备手动送礼逻辑保持不变。
