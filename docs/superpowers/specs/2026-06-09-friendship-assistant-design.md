# 友谊助手 (FriendshipAssistant) 需求文档

> 版本：v2 | 日期：2026-06-09

---

## 一、功能概述

玩家与NPC对话结束后，自动检测背包中与该NPC好感度相关的物品，弹出交互式列表供玩家选择送礼。支持自动送礼模式（GMCM开关控制）。

---

## 二、核心功能

### 2.1 对话后物品检测

- **触发时机**：与可送礼NPC对话结束（对话框关闭）时
- **检测范围**：背包中该NPC好感度五等级的物品：
  - 最爱 (Loved) +80
  - 喜欢 (Liked) +45
  - 普通 (Neutral) +20
  - 不喜欢 (Disliked) -20
  - 讨厌 (Hated) -40
- **不触发条件**：
  - 背包中没有任何该NPC相关物品
  - 当日已向该NPC送过礼物
  - 本周已向该NPC送满 2 次礼物
  - NPC不可送礼（小孩、特殊角色除外）

### 2.2 交互式送礼弹框

- **展示规则**：
  - 五等级分组：最爱 > 喜欢 > 普通 > 不喜欢 > 讨厌
  - 组内按品质排序：铱星 > 金星 > 银星 > 普通
- **交互方式**：玩家点选一个物品，选中即送出，弹窗关闭
- **重试机制**：玩家直接关闭弹窗（ESC/关闭按钮），可再次与NPC对话触发弹窗，直到：
  - 成功送出一个礼物，或
  - 当天结束，或
  - 本周已送满 2 次

### 2.3 送礼约束

- 遵循原版规则：每日最多 1 次，每周最多 2 次
- 玩家可主动选择不喜欢/讨厌物品以降低好感（交恶）

---

## 三、自动交好模式

### 3.1 行为

- GMCM 开关 `AutoGift` 开启后：
  - 对话结束后检测背包中有 最爱/喜欢/普通 物品 → 自动送出一个
  - 静默执行，不弹窗
- **自动送礼优先级**：
  1. 友谊加成最高优先：最爱 (+80) > 喜欢 (+45) > 普通 (+20)
  2. 同级内按品质优先：铱星 > 金星 > 银星 > 普通品质
- **不自动送**：不喜欢 / 讨厌 物品
- **不触发条件**：当日已送礼 / 本周已满 2 次

### 3.2 配置

```json
{
  "AutoGift": false
}
```

- 类型：bool
- 默认值：false
- 配置界面：GMCM

## 四、亮点功能

| # | 功能 | 说明 |
|---|------|------|
| ⭐ | **生日/节日高亮** | 弹框顶部标注 "🎂 今天是XX的生日！送礼友谊加成 ×8！" 或对应节日提示 |
| 🎁 | **上次礼物标记** | 与上次送出的物品相同时，标注 "上次已送过"，避免重复单调 |
| 🔥 | **最爱物品高亮** | 背包中有 NPC 最爱物品时，物品名前加 ⭐ 标记或金色高亮 |

## 五、功能流程

### 手动模式（AutoGift = false，默认）

```
对话结束
    │
    ├─ NPC不可送礼？ ─── 是 ──→ 结束
    ├─ 今日已送礼？  ─── 是 ──→ 结束
    ├─ 本周已满2次？ ─── 是 ──→ 结束
    ├─ 背包无相关物品？ ─ 是 ──→ 结束
    │
    └─ 弹出送礼列表
           │
           ├─ 选一个物品 → 执行送礼 → 结束
           └─ 直接关掉 → 可再次对话触发
```

### 自动模式（AutoGift = true）

```
对话结束
    │
    ├─ NPC不可送礼？ ─────────── 是 ──→ 结束
    ├─ 今日已送礼？ ─────────── 是 ──→ 结束
    ├─ 本周已满2次？ ─────────── 是 ──→ 结束
    ├─ 背包有 最爱/喜欢/普通？ ─ 否 ──→ 结束
    │
    └─ 自动送最优物品（最爱>喜欢>普通，同级按品质）→ 静默完成
```
